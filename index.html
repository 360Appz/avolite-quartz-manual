First-time setup

From unboxing to working DMX output. Follow these steps in order every time you set up the console.

  • 1
    Connect power via UPS
    Plug the Quartz into an external UPS, then the UPS into mains. Auto-switching 80–260V — no voltage selector needed. Never use the rear isolator switch to power off.
  • 2
    Power on via front panel button
    Press and release the front power switch. Console takes ~90 seconds to boot. A radio transmitter on or behind the console may cause interference — keep them away or behind you.
  • 3
    Titan Healthcheck
    On every boot, Titan checks file system and firmware. If issues found, a fix screen appears. Only run fixes if you have time — some take up to an hour. Skip on show day.
  • 4
    Load or start a show
    Select "New Show" for blank or "Load Show" for existing file. You can load from internal storage or USB stick.
    Disk→[Load Show]
  • 5
    Connect DMX lines
    5-pin XLR outputs on rear. Daisy-chain all fixtures on a universe in sequence. Fit a 120Ω terminator (resistor between pins 2 and 3) at the end of each run. Never use passive Y-splitters — they corrupt DMX data. Use active DMX splitters/buffers only.
    To patch to a specific universe and address, type: 2.56 = universe 2, address 56. If a patch goes over 512 channels, console auto-wraps to the start of the next universe.
  • 6
    Enable external monitor (optional)
    Connect via DVI port. Then enable in software:
    Avo+Disk→[Display Setup]→[External Display Disconnected]
    Toggle changes to "External Display Connected". Lock screen background size for Quartz: 1280×800 px.
  • 7
    Set desk lamp brightness
    1–2 XLR 3-pin desk lamp sockets on rear (12V DC, pin 1=–, pin 2=+). Adjust brightness via wheels while in System mode.
    Avo+Disk→use attribute wheels
  • 8
    Save your show regularly
    Titan autosaves periodically, but always save manually before making big changes and after each session. Save to USB for offsite backup.
    Disk→[Save Show]
  • 9
    Shut down correctly — always
    Press front power button once. Wait ~30 seconds for controlled Windows shutdown. Forced shutdown: hold power 5 seconds (loses unsaved data since last autosave).

Patching

Patching tells Titan what lights you have, where they are on DMX, and which button controls them. You must patch every fixture before you can control it. The Patch View window (Open/View → Patch) shows your complete patch at any time.

Plan DMX addresses on the console before you start rigging. Patch in Titan (or Simulator), then view the Patch View window to see the most efficient channel allocation without gaps.

Patching dimmers

  • 1
    Open patch, select Dimmers
    Patch→[Dimmers]
  • 2
    Set DMX line and address
    Softkey shows "DMX Line=" and "Address=". Type new address on keypad, press Enter. To specify line and address together: type e.g. 2.56 for universe 2 address 56.
  • 3
    Assign to a button or fader
    Touch a fixture button, Macro/Executor button, or fader Select button. Button turns dark blue with fixture details. Multiple dimmers can be patched to one handle — press the same button again for each additional channel.
  • 4
    Set User Number (optional)
    Softkey "User Number = xx" lets you assign a custom ID number for the fixture. Used when selecting by number from the keypad.

Patching moving light fixtures

  • 1
    Open patch, select Fixtures
    Patch→[Fixtures]
  • 2
    Select manufacturer
    Browse by softkeys or use Quick Search — type the first few letters of the manufacturer name. Previous/Next page through the library. The console shows a picture of the fixture when selected (if available in the personality).
  • 3
    Select fixture type and mode
    Pick the model and then the DMX mode. The mode on the console must match the mode set on the physical fixture. Modes with a Capture icon support Auto Patch in the visualiser.
  • 4
    Set DMX address and line
    Console shows the first free address. Type a new address if needed. DMX line= softkey changes universe.
  • 5
    Assign to a button
    Touch fixture buttons. DMX address auto-increments for each subsequent fixture. Repeat step 5 to patch multiples rapidly.

Sub-fixtures (multi-cell fixtures)

Some fixtures (e.g. LED battens) contain multiple cells. Patch as one "super fixture" and each cell becomes a sub-fixture. Access all cells together via the main handle, or individually via Unfold or the Attribute Editor.
Unfold→select fixture→ cells appear on individual handles
Unfold→[Exit Unfold]→ back to normal
Sub-fixture keypad syntax: . = all sub-fixtures, n.m = sub-fixture m of fixture n, .m THRO .j = sub-fixtures m through j of all selected. Cell selection is saved inside groups.

You can also change mode and address remotely, and use Identify to flash a fixture so you can locate it in the rig. Requires RDM-compatible splitters/buffers — standard splitters block RDM.

The programmer

BlueIn programmer (dark blue)Fixtures with programmer values show a darker blue button. These values are outputting to the lights and override any playback values.
LTPLTP (Latest Takes Precedence)For non-intensity attributes (colour, position, gobo, beam). The most recently set value wins. If you stop a playback that had colour red, the attribute stays red until something else changes it.
HTPHTP (Highest Takes Precedence)For intensity only. If multiple playbacks control the same dimmer, the highest value wins. A dimmer can never be driven below the highest active playback's value (unless all playbacks are off).
BlindProgrammer Blind modePress Blind (or Avo + Blind) to stop programmer output from reaching the stage. Programme in your head using Capture Visualiser without affecting the show.

Special attribute functions

LocateLocatePuts selected fixtures into a known default position with white light. Start here when beginning to program any fixture.
FlipFlipMoving heads can reach the same beam angle from two different motor positions (pan/tilt). Flip switches between these positions. Solves "dead spots" where a fixture can't reach a position from one motor side.
FanFanSpreads a value across multiple selected fixtures. E.g. if 5 heads are selected and you fan pan, they spread symmetrically around the current pan value. Hold Fan and use wheel. Fan shapes: linear, V-shape, curve.
@@ key (set level)Quickly set intensity to a specific value. Select fixtures, press @, type a number, press Enter. E.g. @ 75 Enter = set to 75%. @ @ = set to full. @ 0 = set to zero.
IncIncludeLoads the contents of a playback (or specific cues from it) back into the programmer for editing. Like "pulling a cue apart" without destroying it.
Include→push up playback fader→[Active Playback] or [Specific Cue]

Cues

A cue is a stored snapshot of lighting values. Push a fader up and the look fades in. Four types of playback exist: Cue (single look), Chase (auto-looping sequence), Cue List (go-button sequence), Timeline (timecoded sequence). All are stored on "handles" — faders, touch buttons, or executor buttons.

Where to store playbacks (handles)

FaderPlayback faderPush up to fade in intensity. HTP controls intensity output. Fader can also control other things via Options (master speed, size, etc.).
VirtualVirtual faderOn-screen fader in the Virtual Faders window — works exactly like a physical fader. No hardware needed. Ideal for touch-screen-only shows.
TouchTouch button (Playbacks window)Toggles or flashes the playback. Behaviour set by Key Profiles (latch, flash, timed flash, swop).
ExecMacro/Executor buttonPhysical programmable button. Key Profiles set behaviour. Good for frequently-triggered effects or instant looks.

  • 2

Chases

A chase is a sequence of cues that plays automatically in a loop. Each step can be a complete lighting state. Chases are ideal for repeating effects — colour chases, position sweeps, strobe patterns, crowd blinders.

Recording a chase

  • 3
    Repeat for all steps
    Add as many steps as needed. Each step gets a step number. No limit on the number of steps.

Cue lists

A cue list is a numbered sequence of individual cues. You step through them by pressing Go. Unlike chases, cue lists don't auto-loop — you control every advance. Used in theatre, broadcast, and complex live productions where each scene is precisely programmed.

Creating a cue list

  • 1
    Record first cue to a fader
    Record→touch fader→[Create Cue List]
  • 2
    Build and record each cue
    Set your look, then Record → same fader. Cues are numbered 1, 2, 3... You can insert fractional cues (e.g. 2.5) between existing ones later.
  • 3
    Advance with Go
    Press Go button (section H) to step to the next cue. Screen shows current and next cue name, timing, and tracking state.

Tracking (LTP persistence)

In tracking mode (default), attributes "track" from cue to cue. If you set lights red in cue 1 and don't change colour in cue 2, the lights remain red in cue 2. Only changed attributes are stored per cue — making file sizes smaller and edits faster. Tracking state is shown in Cue List View (T = tracking, B = block).
TrackTracking on (default)Values persist from previous cue unless explicitly changed. One edit to cue 1 may ripple forward through many cues.
BlockBlock trackingA "Block" cue stops tracking — it records all attribute values explicitly. Nothing tracks through it from earlier cues.

Effects

Titan's effects engine creates automatic movement, colour cycling, strobing, and animated patterns. Three systems: Shape Generator (preset), Key Frame Shapes (custom), and Pixel Mapper (grid animations).

Shape Generator

  • 1
    Select fixtures and attribute group
    Select fixtures, then press the attribute button for the type of shape (e.g. Position for pan/tilt movement, Colour for colour cycle).
  • 2
    Open Shape Generator
    Shapes→[Generate Shape]
  • 3
    Pick a shape type
    Circle, sine wave, square wave, triangle, random, saw, ramp. Shape immediately runs on selected fixtures.
  • 4
    Adjust with wheels
    Wheel A = Speed (BPM). Wheel B = Size (amplitude of movement/colour change). Wheel C = Spread/Phase (offset between fixtures, creating a wave effect through the rig).
  • 5
    Set direction and phase offset
    Direction reverses the shape (e.g. sine runs backwards). Phase spread staggers when each fixture starts its cycle — creates the "ripple" or "wave" effect across the rig.
  • 6
    Record to a playback
    Record→touch fader→fader controls effect size or speed (set in Options)

  • 3

Networking

Titan supports full professional lighting network protocols. The Quartz can control up to 64 universes total using TNP nodes, work in multi-console sessions, and run backup consoles for show-critical reliability.

DMX protocols

ProtocolWhat it isWhen to use
DMX512 (XLR)Direct hardware DMX over 5-pin XLR cableShort distances, simple rigs, direct-connected fixtures
Art-NetDMX over Ethernet (UDP packets)Longer distances, multiple universes, remote DMX nodes
sACN (streaming ACN)DMX over Ethernet (multicast)Large scale, many universes, industry standard for larger shows

TNP (TitanNet Processor)

The TNP is a rack-unit device that receives TitanNet data from the console over Ethernet and outputs physical DMX lines. Each TNP adds more DMX universes — up to a total of 64 universes across the console + all TNPs.
ConnectAdding a TNPConnect TNP to the same network as the console. In System menu → TitanNet, assign it to the session. Map DMX lines to TNP outputs in DMX Settings.
ModeTNP Console ModeA TNP can also run as a lightweight console — loading a show file and outputting DMX independently. Used as a backup or secondary output node.
On pre-Titan v12 show files loaded on newer software, TNP DMX line assignments may need to be manually re-assigned. Always verify DMX Settings after loading old show files.

Backup console

For show-critical reliability, a second console can run as a backup. The backup console syncs the show file from the master in real time. If the master fails, you manually switch the backup to take control.
Disk→[Multi-User]→[Backup]→link to master console session
D9, D7, and Arena have an internal network switch with an independent UPS. This allows the network switch to keep running for ~5 minutes during a power cycle — so a backup console connected through the internal switch stays live even if the main console reboots. The Quartz has no internal switch — use an external switch.

Network best practices

IPIP addressingArt-Net uses 2.x.x.x or 10.x.x.x subnet. sACN uses multicast. Consoles and nodes must be on the same subnet. Set static IPs — avoid DHCP for show-critical networks.
IsoNetwork isolationKeep your lighting network isolated from venue Wi-Fi and internet. A separate switch dedicated to the lighting network prevents interference and packet loss.

Curves define how dimmer channels respond to fader position. Linear = fader at 50% = output at 50%. Other curves: square law (more gradual at the bottom, faster at top), logarithmic, or custom S-curves. Set per dimmer channel in Patch View → Curves column.
